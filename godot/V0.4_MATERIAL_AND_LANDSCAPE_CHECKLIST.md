# Granny HD Mobile — V0.4 implementation checklist

This checklist is grounded in the current Godot 4.4.1 project, source code, and archived original candidate material files. It is not a claim that all items are already implemented.

## P0 — Landscape / screen (done in commit fa7d6c2)
- [x] `godot/project.godot`: switch `window/handheld/orientation` from `1` (**Portrait**) to `0` (**Landscape**)
- [x] `godot/project.godot`: add `window/stretch/aspect="expand"`; retain `canvas_items` for clear 3D resolution and UI scaling
- [ ] Android installation: check no portrait letterboxing and that touch UI fits landscape, including cutouts

## P1 — Import the **actual** texture PNGs (not done)
Current texture source: `Granny_HD_Mobile_CloudBuild_V0_2.zip`, at `Assets/GrannyHD/Textures/{name}/`.
The GitHub repository currently has no `godot/textures` PNG folders.

Move the four files `Albedo.png`, `Normal.png`, `AO.png`, `MetallicSmoothness.png` into each corresponding `godot/textures/{name}/` path:

| Folder | Surface | Current candidate texture resolution |
| --- | --- | --- |
| `Floor` | old floor | 2048×2048 |
| `Walls` | worn wall | 2048×2048 |
| `Ceiling` | aging ceiling | 2048×2048 |
| `SafeBody` | safe box | 1024×1024 |
| `SafeDoor` | safe door | 1024×1024 |
| `Crate` | crate and lid | 1024×1024 |
| `CrateMetal` | crate metal fittings | 1024×1024 |
| `SteelPlate` | rusty plate | 1024×1024 |

- [ ] Add these source textures to the repository (8 sets, 32 PNGs).
- [ ] Godot: set `Albedo.png` as base-color texture, enable `Normal.png` and `AO.png`.
- [ ] Convert Unity-style `MetallicSmoothness.png` channels into Godot-compatible metallic/roughness maps: **smoothness is not roughness**; roughness = 1 - smoothness. Verify channel packing before converting. Do not wire the map directly into Godot's roughness slot.
- [ ] Set reasonable tile counts/UV scaling so floor and wall patterns are not stretched across 9 m.
